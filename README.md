## 🏫 About 42
[42](https://42.fr/en/homepage/) is a global software engineering school that offers a unique educational model. It features a project-based, peer-to-peer learning environment without teachers or traditional classes. The curriculum focuses heavily on C/C++ programming, algorithms, system administration, and software architecture.

All projects in this repository strictly adhere to the **42 Norm**, which implies rigorous rules on code formatting, variable declarations, and function length (maximum 25 lines per function).
